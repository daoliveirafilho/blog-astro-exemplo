# Bem vindos, vejam os componentes e como integrar nos posts.

## GitHub Gists

Embed GitHub Gists usando `#gist` com o seu shortcode:

#gist daoliveirafilho/641127ed6a1dbee542c0bdcc243e09de

## Documentos PDF

Embed documentos PDF usando `#pdf` com o seu shortcode:

#pdf rekall.log.br/assets/pdf/profile.pdf

## Audios e videos

Embed Asciinema usando `#asciinema`, Google Maps usando `#googlemaps`, SoundCloud usando `#soundcloud`, Vimeo usando `#vimeo`, Wistia usando `#wistia` e YouTube usando `#youtube`:

#youtube y6k64SHrwDk
